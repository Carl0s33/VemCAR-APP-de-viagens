# Vem Car — Mobile Mobility Solution

O **Vem Car** é uma interface de mobilidade urbana de alta fidelidade projetada para otimizar o transporte na região de **Nova Cruz e Santo Antônio/RN**. O projeto foca em um design minimalista, utilizando a estética *Matte Dark* para oferecer uma experiência de uso intuitiva e moderna.

---

## 🛠 Tecnologias e Ferramentas

O projeto foi construído utilizando um stack moderno focado em performance e manutenibilidade:

*   **Core**: React 18 com Vite para um ambiente de desenvolvimento ultra-rápido.
*   **Animações**: Framer Motion para transições de estado fluidas e micro-interações.
*   **Interface**: Lucide React para iconografia consistente e escalável.
*   **Design**: Prototipagem avançada realizada no Figma.

---

## 📱 Destaques do Desenvolvimento

### Experiência do Usuário (UX)
*   **Fluxo de Destino**: Sistema de busca com caixa dupla de rota e gerenciamento de destinos frequentes.
*   **Gestão de Pagamentos**: Implementação de *bottom sheets* animados para seleção de métodos como Pix e Dinheiro.
*   **Visualização em Tempo Real**: Mapas com estilo *Amoled Dark* integrados à interface de acompanhamento do motorista.

### Design Visual (UI)
*   **Matte Aesthetic**: Uso de superfícies foscas e sombras suaves para reduzir a fadiga visual.
*   **Consistência**: Sistema de componentes padronizado com raios de borda entre 24px e 32px.

---

## 🚀 Instalação e Execução

Para replicar o ambiente de desenvolvimento local:

1.  **Dependências**:
    ```bash
    npm install
    ```
2.  **Execução**:
    ```bash
    npm run dev
    ```
3.  **Ambiente**: Acesse a porta local indicada e utilize o modo de inspeção do navegador para visualização em proporções mobile (ex: iPhone 12/14).
